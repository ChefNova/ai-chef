# CP2 Prompting Evidence

This directory contains the sanitized receipts for the controlled prompting study.

The final study requires the same or carefully controlled ChefNova scenarios to be run across at least two AI platforms, covering typical, edge, and failure cases. Preserve enough context to show the prompt, relevant output, and the observed behavior.

The two platform files in this package define the intended storage locations. Replace their evidence placeholders with the actual outputs/screenshots from the completed study; no fabricated model result is included.
