# ChefNova CP2 Prototype

This is a lightweight Streamlit proof-of-concept for the critical CP2 journey.

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

The prototype runs in demo mode without an API key. The purpose is to demonstrate the interaction and decision-rights design; it is not the final production implementation.

## Critical journey

Receipt / grocery text → editable inventory → confirmation → meal request → constraint display → candidate recipes → feasibility explanation → refinement.
